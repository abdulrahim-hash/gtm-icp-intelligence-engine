# Loom Walkthrough Script

**Target: 6–8 minutes**

**Opening:** “I built this GTM ICP Intelligence Engine because connected tools are not enough if the system cannot explain why a lead qualified, whether a provider call already happened, or whether outreach is still safe.”

**Architecture:** Show Supabase as canonical state, n8n as orchestration, and providers behind brokers.

**Account to contact:** Show intelligence/scoring gates, company/seniority acquisition, local persona classification and identity aliases.

**Reliability:** Explain immutable attempts, 429 retry state, CRM CREATE/UPDATE/NOOP planning and centralized credentials.

**Outreach safety:** Show that generation is separate from approval and dispatch. Explain suppression and provider live gates.

**Results:** 39 scored accounts, 5 fully measured pilot accounts, 7 canonical contacts, 7 verified emails, 7 HubSpot mappings, 7 planned tasks, 0 accidental sends.

**Close:** “The project demonstrates GTM Engineering as revenue infrastructure that can explain its decisions, recover from failure and safely re-run.”
