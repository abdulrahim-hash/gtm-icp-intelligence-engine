# Case Study — GTM ICP Intelligence Engine

## Problem

B2B outbound often becomes disconnected tools with weak state control. The system cannot reliably answer why an account qualified, whether a provider call already happened, whether a CRM write duplicated, or whether outreach is still safe.

## Objective

Build an auditable GTM system for account intelligence, contact acquisition, identity resolution, verified enrichment, CRM synchronization, controlled outreach, lifecycle handling and QA.

## Solution

Five pilot accounts were fully measured through Website Intelligence and deterministic scoring. Contact acquisition moved to one Prospeo company/seniority search with persona classification performed locally. Provider observations resolve into canonical contacts conservatively. Enrichment permits verified email only and disables mobile reveal. HubSpot is an external target with CREATE/UPDATE/NOOP planning. Outreach separates planning, rendering, approval, readiness and dispatch.

## Result

Validated baseline:

- 39 scored accounts
- 5 fully measured pilot accounts
- 7 canonical decision-makers
- 28 identity aliases
- 7 verified emails
- 7 HubSpot mappings
- 7 planned outreach tasks
- 0 real outreach attempts
- 0 accidental sends

## What this demonstrates

Data contracts, GTM systems thinking, provider abstraction, identity resolution, CRM integration, idempotency, retry semantics, lifecycle state machines, human approval gates and auditability.

The next scale target is 75–150+ accounts and 100–250+ outbound-ready contacts. That is a roadmap target, not a result claimed by this case study.
