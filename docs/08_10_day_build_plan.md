# Project 01 — 10-Day Build Plan

The ten-day objective is a **live customer-acquisition MVP**, not every future feature.

## Day 1 — Research + architecture
- ICP hypothesis
- offer
- manual seed cohort
- Clay prototype
- vendor-agnostic architecture decision

## Day 2 — Data foundation
- Supabase schema
- n8n ingestion
- normalization
- deduplication

## Day 3 — Account discovery
- source real US commercial cleaners
- ingest first 100–300 accounts
- establish hard gates

## Day 4 — Website intelligence
- crawl/research target websites
- store evidence
- classify operator type / commercial focus / GTM maturity

## Day 5 — Scoring V1
- Fit
- Need
- Signal
- Confidence
- tiering
- manual QA

## Day 6 — Decision makers + contacts
- identify target roles
- verify contacts only for qualified accounts
- create outbound-ready cohort

## Day 7 — Offer + messaging
- finalize outreach hypotheses
- create personalized research payload
- create test cohorts

## Day 8 — GoHighLevel pipeline
- RepFlow/Saray sales pipeline
- fields/tags
- routing
- opportunity creation
- attribution

## Day 9 — Launch controlled outbound
- small, measured cohort
- record delivery/reply/outcome evidence
- no invented results

## Day 10 — Analyze + present
- experiment findings
- scoring/message iteration
- GitHub cleanup
- architecture visual
- Loom outline/recording
- case-study draft

## Completion criterion

Project 01 is complete when the acquisition system is live and generating measurable market feedback. A closed customer would be valuable evidence but is not required to call the engineering MVP complete.
